H-Net Experiment
#

Toy Experiment

This experiment trains a small 1-stage H-Net on raw bytes, on a CPU. It shows that the model learns where to put boundaries without a tokenizer. It is not a reproduction of the results of the paper.

  • Data: Tiny Shakespeare, 1.1 MB of text. The first 90% is for training and the last 10% for validation.
  • Model: encoder and decoder of 2 Transformer blocks at width 128, a main network of 4 blocks at width 192, and a target of $N = 4$ bytes for each chunk. It has 2.67 M parameters: 1.77 M in the main network, 0.84 M in the encoder, the decoder and the routing module, and 0.07 M in the byte embedding and the output head.
  • Training: 1,500 steps of 16 sequences of 256 bytes. It took 448 seconds on an Apple M1 CPU.

Run experiments/run_toy.py to train the model and save the results. Then scripts/figures.py draws the figures from the saved results.

The loss fell to 2.31 bits per byte. The compression started at 2.99 bytes for each chunk, because the routing module starts as a cosine distance of the encoder outputs. It went down to 2.15 in the first 50 steps, then up to 2.87 at the end. It did not get to the target of 4 in 1,500 steps. The ratio loss has a small weight, $\alpha = 0.03$, so the next-byte loss controls the start of training.

Nothing in the model knows about words, but most chunks are words or parts of words. Most spaces are a chunk of their own. Thus the first byte of each word is predicted from a chunk that ends at the space. Common words ("we", "me", "the", "fox", "over") are one chunk. Less common words are cut into parts ("q|uick", "fu|rt|her"). Some chunks join a word to the next space ("lazy␣") or span two words ("irst Cit", "proceed any␣").

Settings

The training settings. log_every is the number of steps between two evaluations, and eval_batches is the number of validation batches in each evaluation.

9@dataclass
10class ToyConfig:
11    seq_len: int = 256
12    batch_size: int = 16
13    steps: int = 1500
14    warmup: int = 100
15    lr: float = 1e-3
16    log_every: int = 50
17    eval_batches: int = 8
18    seed: int = 0
#

Model

A 1-stage H-Net: widths $D^0 = 128$ and $D^1 = 192$, and $N^0 = 4$. The other settings are the defaults in the configuration, with $\alpha = 0.03$.

21def model_config() -> HNetConfig:
22    return HNetConfig(d_model=(128, 192), target_ratio=(4.0,), outer_layers=2, main_layers=4, n_heads=4)
#

Batches

Windows of 257 bytes from random positions in the data: 256 inputs and the next byte for each. All windows have the same length, so there is no padding at the byte level. The chunks of each window still have different lengths.

25def batch(data: torch.Tensor, seq_len: int, batch_size: int, generator: torch.Generator) -> torch.Tensor:
26    starts = torch.randint(len(data) - seq_len - 1, (batch_size,), generator=generator)
27    return torch.stack([data[start : start + seq_len + 1] for start in starts])
#

Evaluation

The loss in bits per byte, and the mean number of bytes for each chunk. A fixed seed gives the same batches at each evaluation, so that the points of the curves can be compared.

30@torch.no_grad()
31def evaluate(model: HNetLM, data: torch.Tensor, config: ToyConfig) -> tuple[float, float]:
32    generator = torch.Generator().manual_seed(1234)
#

For each validation batch: the loss, and the routing output of stage 0. All windows hold data, so the mask is true everywhere.

33    nats, ratios = [], []
34    for _ in range(config.eval_batches):
35        tokens = batch(data, config.seq_len, config.batch_size, generator)
36        loss = model.loss(tokens, torch.ones_like(tokens, dtype=torch.bool))
37        routing = loss.routings[0]
#

$\mathcal{L}_{\text{AR}}$ in nats, and $L / M$, the number of positions divided by the number of chunks.

38        nats.append(loss.autoregressive.item())
39        ratios.append((routing.mask.sum() / routing.b.sum()).item())
# $$\text{bits per byte} = \mathcal{L}_{\text{AR}} / \ln 2$$

Dividing by $\ln 2$ changes nats to bits, and $\mathcal{L}_{\text{AR}}$ is a mean over bytes.

40    return sum(nats) / len(nats) / math.log(2), sum(ratios) / len(ratios)
#

Training

Train the model from a fixed seed and return it with the curves. The optimizer settings below are common settings for small language models, not settings from the paper.

43def train(train_data: torch.Tensor, valid_data: torch.Tensor, config: ToyConfig) -> tuple[HNetLM, dict]:
44    torch.manual_seed(config.seed)
45    model = HNetLM(model_config())
#

AdamW with $\beta = (0.9, 0.95)$ and weight decay 0.1, with one learning rate for each stage, from $N_{\text{GPT}} = N^0$ as in the learning rate for each stage. The outer stage gets 2.45 times the base rate of $10^{-3}$.

46    n_gpt = math.prod(model.config.target_ratio)
47    optimizer = torch.optim.AdamW(model.param_groups(config.lr, n_gpt), betas=(0.9, 0.95), weight_decay=0.1)
#

A linear warmup over the first 100 steps, then a constant learning rate.

48    schedule = torch.optim.lr_scheduler.LambdaLR(
49        optimizer,
50        lambda step: min(1.0, (step + 1) / config.warmup),
51    )
# 
52    generator = torch.Generator().manual_seed(config.seed)
53    curves = dict(step=[], train_bpb=[], valid_bpb=[], ratio=[])
#

Evaluate at step 0 and every log_every steps, including after the last step.

54    for step in range(config.steps + 1):
55        if step % config.log_every == 0:
56            model.eval()
57            valid_bpb, ratio = evaluate(model, valid_data, config)
58            model.train()
59            curves['step'].append(step)
60            curves['valid_bpb'].append(valid_bpb)
61            curves['ratio'].append(ratio)
62        if step == config.steps:
63            break
#

One training step on $\mathcal{L}$, the next-byte loss plus the ratio loss, with the gradient norm clipped to 1.

64        tokens = batch(train_data, config.seq_len, config.batch_size, generator)
65        loss = model.loss(tokens, torch.ones_like(tokens, dtype=torch.bool))
66        optimizer.zero_grad()
67        loss.total.backward()
68        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
69        optimizer.step()
70        schedule.step()
# 
71        if step % config.log_every == 0:
72            curves['train_bpb'].append(loss.autoregressive.item() / math.log(2))
73    return model, curves

Chunks of a text

Run the model on one text and cut the text where $b_t = 1$. This gives the chunks in the figure above.

76@torch.no_grad()
77def chunk_text(model: HNetLM, text: str) -> list[str]:
78    tokens = torch.tensor([list(text.encode())])
79    _, routings = model(tokens, torch.ones_like(tokens, dtype=torch.bool))
80    starts = routings[0].b[0].nonzero().flatten().tolist() + [tokens.shape[1]]
81    raw = text.encode()
82    return [raw[start:end].decode(errors='replace') for start, end in zip(starts, starts[1:])]
