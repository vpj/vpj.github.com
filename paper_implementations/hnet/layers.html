H-Net Layers
#

Layers

These are the sequence layers of the networks in H-Net: the encoder, the main network and the decoder. They are standard pre-norm Transformer blocks. Dynamic chunking does not depend on the type of layer. It only needs layers that are causal: the output at a position must not depend on later positions.

The paper uses Mamba-2 layers in the encoder and the decoder, and Transformer layers in the main network. Mamba-2 needs custom GPU kernels, so we use Transformer blocks in all three networks. This changes the result: the paper found that encoders and decoders with state space layers make better chunks than encoders with Transformer layers. The authors give the reason as a stronger bias of state space layers for compression. Our encoder also sees the positions through rotary embeddings, which a Mamba-2 layer does not need.

2import torch.nn.functional as F
3from torch import nn

RMS normalization

$$\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum_i x_i^2 + \epsilon}} \odot w$$

where $d$ is the width and $w$ is a learned scale. It divides each vector by its root mean square, without the subtraction of the mean that layer normalization does.

6class RMSNorm(nn.Module):
# 
7    def __init__(self, d_model: int, eps: float = 1e-5):
8        super().__init__()
9        self.eps = eps
10        self.weight = nn.Parameter(torch.ones(d_model))
# 
12    def forward(self, x: torch.Tensor) -> torch.Tensor:
13        return x * torch.rsqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps) * self.weight
#

Rotary position embedding

Attention by itself does not know the order of its inputs. Rotary embeddings rotate each pair of dimensions of the queries and keys by an angle $m \theta_i$, where $m$ is the position and $\theta_i = 10000^{-2i/d_h}$. Then the dot product of a query at position $m$ and a key at position $n$ depends on the offset $m - n$. In the main network, the positions are the chunks, not the bytes.

16class RotaryEmbedding(nn.Module):
#

$\theta_i = 10000^{-2i/d_h}$ for each pair $i$ of dimensions, where $d_h$ is the width of a head.

17    def __init__(self, d_head: int, base: float = 10_000.0):
18        super().__init__()
19        self.register_buffer('inv_freq', base ** (-torch.arange(0, d_head, 2).float() / d_head), persistent=False)
# 
21    def forward(self, x: torch.Tensor) -> torch.Tensor:
#

The angle $m \theta_i$ for each position $m$ and each pair $i$.

22        positions = torch.arange(x.shape[-2], device=x.device, dtype=torch.float32)
23        angles = torch.outer(positions, self.inv_freq)
24        cos, sin = angles.cos().to(x.dtype), angles.sin().to(x.dtype)
#

Rotate each pair $(x_1, x_2)$ by its angle $m \theta_i$:

\begin{align*} x_1' &= x_1 \cos m \theta_i - x_2 \sin m \theta_i \\ x_2' &= x_1 \sin m \theta_i + x_2 \cos m \theta_i \end{align*} 
25        x1, x2 = x[..., 0::2], x[..., 1::2]
26        rotated = torch.stack((x1 * cos - x2 * sin, x1 * sin + x2 * cos), dim=-1)
27        return rotated.flatten(-2)

Transformer block

A pre-norm block: causal self-attention, then a multilayer perceptron (MLP). Each one reads a normalized copy of $x$ and adds its output to $x$.

30class TransformerBlock(nn.Module):
# 
31    def __init__(self, d_model: int, n_heads: int, mlp_ratio: int = 4):
32        super().__init__()
33        self.n_heads = n_heads
34        self.attention_norm = RMSNorm(d_model)
35        self.qkv = nn.Linear(d_model, 3 * d_model, bias=False)
36        self.out = nn.Linear(d_model, d_model, bias=False)
37        self.rotary = RotaryEmbedding(d_model // n_heads)
38        self.mlp_norm = RMSNorm(d_model)
39        self.mlp = nn.Sequential(
40            nn.Linear(d_model, mlp_ratio * d_model, bias=False),
41            nn.GELU(),
42            nn.Linear(mlp_ratio * d_model, d_model, bias=False),
43        )
# 
45    def forward(self, x: torch.Tensor) -> torch.Tensor:
#

The queries, keys and values of all heads, from one projection.

46        batch, length, d_model = x.shape
47        qkv = self.qkv(self.attention_norm(x)).view(batch, length, 3, self.n_heads, d_model // self.n_heads)
48        q, k, v = qkv.permute(2, 0, 3, 1, 4)
#

is_causal=True masks the later positions. This is what makes the whole H-Net causal, together with the routing module, which looks only at the previous position. It is also why padding at the end of a row never changes a position with data.

49        attention = F.scaled_dot_product_attention(self.rotary(q), self.rotary(k), v, is_causal=True)
# 
50        x = x + self.out(attention.transpose(1, 2).reshape(batch, length, d_model))
51        return x + self.mlp(self.mlp_norm(x))

Stack

One network of the H-Net: a number of blocks, then an RMS normalization at the end. The paper calls the last normalization network normalization and puts one at the end of each encoder, decoder and main network.

The reason is the residual connections between the networks. In a pre-norm stack, the norm of the vectors grows with each block. Without a final normalization, the output of the deep main network would be much larger than the encoder output that the residual adds to it. Then the detail of each byte would be lost. The normalization makes the two terms of the same size.

54class Stack(nn.Module):
# 
55    def __init__(self, d_model: int, n_layers: int, n_heads: int):
56        super().__init__()
57        self.blocks = nn.ModuleList([TransformerBlock(d_model, n_heads) for _ in range(n_layers)])
58        self.norm = RMSNorm(d_model)
# 
60    def forward(self, x: torch.Tensor) -> torch.Tensor:
61        for block in self.blocks:
62            x = block(x)
63        return self.norm(x)
